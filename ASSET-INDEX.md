# Asset index

`source` is the path inside `website-n-assets/Website/` in the original
project folder. **That folder is not in this zip** — 1.6 GB, 161 files, many
of them 15-23 MB PNGs. Keep it; it is the master set.

Of 152 images in the masters, 126 are unique: the Zingara and Possah folders
each keep a flat copy of every board alongside the foldered copies, so 26 are
exact duplicates. The curation script hashes and drops them.

Regenerate:

```
python tools/curate-assets.py <path-to>/website-n-assets/Website assets
```

NUANSE's own marks are handled separately and live in `site/assets/brand/`,
with their own README. Regenerate those with `tools/build-brand-assets.py`.
